VIDEO-OH Analytics

VIDEO-OH Analytics is a private analytics tool used by the developer to analyze YouTube channels the developer is authorized to manage.

Read-only access only.

The application uses Google OAuth to request read-only access to YouTube and YouTube Analytics data. It does not upload, edit, delete, or publish YouTube content.

Purpose

Authorized YouTube analytics data is used only for internal performance analysis and to improve video content.

Data handling

OAuth credentials and analytics data are kept on developer-controlled systems. Google user data is not sold, used for advertising, or shared with third parties for unrelated purposes.

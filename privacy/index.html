Privacy Policy for VIDEO-OH Analytics

Last updated: October 3, 2026

Overview

VIDEO-OH Analytics is a private tool used by the developer for internal analysis of YouTube channels the developer is authorized to manage. Access to Google user data occurs only after explicit OAuth authorization by the account holder.

Google data accessed

The application requests only read-only YouTube permissions. Depending on data available from the YouTube APIs, the application may access channel and video identifiers and analytics such as views, engaged views, watch time, average view duration, average view percentage, likes, comments, shares, subscriber changes associated with video watch pages, traffic-source information, and audience-retention information.

The application does not request permission to upload, edit, delete, or publish YouTube content.

How the data is used

Google user data is used solely for internal analytics, performance measurement, and improvement of video content managed by the developer. It is not used for advertising, unrelated profiling, resale, or any purpose unrelated to the stated analytics function.

Storage and security

OAuth refresh credentials are stored on a developer-controlled system in encrypted credential storage. Short-lived access credentials are used only as needed for API requests. Analytics snapshots are stored locally on the developer-controlled system and are not published by this website.

Retention and deletion

The collector is configured to keep at most 600 analytics snapshots per platform, approximately 150 days at the planned six-hour collection interval. OAuth credentials remain stored until they are revoked, replaced, or deleted by the developer.

Access can be revoked at any time from the user's Google Account permissions. The developer can also delete locally stored credentials and analytics data upon request.

Sharing

Google user data is not sold and is not shared with third parties for advertising or unrelated purposes.

Google API Services User Data Policy

VIDEO-OH Analytics' use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
